# 🐰 dramagotchi-terminal

**Dramagotchi** is a Python-powered terminal pet with dynamic emotions and AI-powered conversations. 🐰💔

Care for, interact with, and even talk to your virtual pet directly in your terminal. But be careful: neglecting your pet could lead to dramatic emotional crises!

## 🚀 Features

- **Dynamic Emotions**: Hunger, happiness, and energy levels that change over time.
- **AI Conversations**: Chat naturally with your pet, powered by OpenAI.
- **Personality Types**: Randomly assigned traits (needy, playful, grumpy) that affect interactions.
- **Interactive Terminal UI**: Nostalgic ASCII art and emotional animations using Rich.
- **Persistent State**: Saves and loads your pet's state automatically.

## 🛠️ Tech Stack

- **Python 3.x**
- **Rich** (for beautiful terminal output)
- **OpenAI API** (GPT-powered responses)
- **Matplotlib** (emotion statistics visualization)

## 📦 Installation

### Clone the Repository
```bash
git clone https://github.com/your-username/dramagotchi-terminal.git
cd dramagotchi-terminal
```

### Install Dependencies
```bash
pip install -r requirements.txt
```

## ▶️ Running the Game
Start the pet:
```bash
python main.py
```

Interact through the intuitive menu to feed, play, sleep, or chat with your pet.

## 📊 Emotion Charts
Check your pet's emotional stats anytime:
